# 原版界面与逻辑记录（dart_simple_live）

来源：实际运行 `F:\SimpleLive\simple_live_app.exe`（Windows，1600×900 / 1938×1038 两种窗口尺寸）
逐页点击截图 + 源码 `simple_live_app/lib/modules/**` 对照。对照截图见 `docs/img/`。

## 1. 外壳

- 原生标题栏：标题「Simple Live」，右侧最小化/最大化/关闭。
- **左侧竖向图标栏**（约 56 px，深色）自上而下：首页、关注、分类、设置。
  当前页高亮（图标变色 + 圆角底色）。
- 内容区顶部（首页/分类共有）：**平台 Tab 居中**，带平台小图标：
  哔哩哔哩 / 斗鱼直播 / 虎牙直播 / 抖音直播 / 快手直播。
- 首页右上角有搜索框（分类页没有）。

## 2. 页面与跳转

```
首页 ──点卡片──▶ 直播间
分类 ──点二级分类──▶ 分类房间列表 ──点卡片──▶ 直播间
关注 ──点卡片──▶ 直播间
设置 ──点列表项──▶ 设置详情（返回箭头 + 居中标题）
```

### 首页

- 平台 Tab 下方直接是**封面卡片网格**（约 5 列，随宽度自适应）。
- 卡片：封面图（16:9）+ 标题（最多两行）+ 主播名 + 人气值（「1350.4 万」这种写法）。
- 顶部有一条横幅：「2026英雄联盟全球总决赛二路…」（运营位）。

### 分类

- 一级分区**纵向堆叠**，每个分区标题（网游 / 手游 / 单机游戏 / 娱乐 / …）。
- 分区内是**二级分类图标网格**（图标 48×48 + 名称），最后一项固定为「显示全部」。
- 点二级分类进入**分类房间列表**：
  - 顶部：返回箭头（左）+ 居中标题（如「英雄联盟」）。
  - 内容：**6 列封面卡片**，卡片右下角有收藏心形；右下角有悬浮刷新按钮。

### 关注

- 关注主播列表（首次为空态）。相关设置在「关注设置」：
  自动更新关注直播状态（开关）、自动更新间隔（默认 0 小时 10 分钟）、
  更新线程数（8）、关注每页数量（200）。

### 设置

- 列表项（带左侧图标 + 右侧箭头）：
  数据同步 / 链接解析 / 外观设置 / 主页设置 / 播放页设置 / 直播设置 /
  多开设置 / 弹幕设置 / 关注设置 / 定时关闭 / 其他设置 / 免责声明 / 开源主页。
- 详情页样式：顶部返回箭头 + 居中标题；内容是**卡片式行**，右侧显示开关、数值或箭头。
- 首次启动会弹「免责声明」对话框，需点「已阅读并同意」。

## 3. 直播间（二级页面）

- 顶部：返回箭头 + 房间标题 + 分区/主播信息 + 状态标签；右下角「关注/分享/屏蔽/标签」等操作。
- 视频区铺满，超出比例时留黑边（Contain）。
- **滚动弹幕**叠在视频上方，多行、彩色、带描边。
- 底部控制条：播放/暂停、时间、音量、设置、清晰度（如「2K」）、线路（「线路01」）、
  弹幕开关、全屏。
- 右侧 **300 px 聊天面板**：顶部头像 + 昵称 + 在线人数；Tab「聊天 / SC / 关注 / 主播…」；
  下面是消息列表（主播名 + 内容，可滚动）。

## 4. 弹幕设置项（源码 `danmu_settings_page.dart`）

| 分组 | 项 |
|------|----|
| 屏蔽 | 启用弹幕屏蔽、启用关键词屏蔽、启用用户屏蔽、打开屏蔽管理 |
| 显示 | 显示区域、显示几行（优先按区域显示，超限自动收紧）、显示弹幕表情 |
| 样式 | 滚动速度（弹幕持续秒数，越小越快）、不透明度、字体大小、字体粗细、弹幕描边、描边宽度、帧率上限 |
| 重点动态 | 全屏显示重点动态、动态统计跨度、动态展示时间、动态起显次数、动态保留数量 |
| 重复过滤 | 过滤模式（按内容/按用户）、过滤窗口、过滤步长、平台补偿（按平台覆盖） |

## 5. 当前 Tauri 实现对照

已按本记录完成全部一级/二级页面，截图见 `docs/img/`：

- 左侧图标栏、五平台 Tab（带图标、未接入平台标记）、首页封面网格与分页。
- 分类：一级分区纵向堆叠 + 二级图标网格 + 「显示全部」；分类房间页 6 列封面卡、返回、刷新。
- 搜索页：胶囊输入框 + 平台 Tab + 最近搜索 + 链接解析 + 房间号直达。
- 关注页：标签、按状态/平台筛选、网格/列表、标签编辑、取消关注、导入导出。
- 设置列表 17 项 + 二级详情（外观/主页/播放页/直播/多开/弹幕/关注/定时/其他/同步/链接/账号/免责声明/关于）。
- 直播间：视频、顶部信息浮层、滚动弹幕、聊天面板五个 Tab、底部播放控制条、底部动作栏、自动隐藏、全屏、画中画。
- 弹幕参数：显示区域、行数、字体、粗细、速度、不透明度、描边、帧率、安全边距、屏蔽、重复过滤、快速设置面板。
- 首次启动免责声明、深浅色主题、主题色、观看记录、本地持久化。

与原版的差异：

- 原版 Flutter + media_kit/mpv；这里 WebView2 + mpegts.js，播放观感依赖 WebView2 解码能力。
- 桌面版不保留移动端专属设置（后台保活、小窗、iOS 硬解等）。
- 斗鱼取流已通过 WebView 签名 + 本机流代理打通；虎牙 Tars 弹幕、抖音/快手接口仍受协议层限制，详见 README。
- 哔哩哔哩扫码 / Cookie 登录、斗鱼 Cookie 登录已接后端；多开同屏、自动更新仍是占位。
